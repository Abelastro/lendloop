# Test reports

These artifacts are generated by `npm run test:report`.

| File                             | Purpose                                                         |
| -------------------------------- | --------------------------------------------------------------- |
| `test-summary.md`                | Human-readable summary of suites, pass rate, and coverage       |
| `junit.xml`                      | JUnit XML for CI dashboards and GitHub test reporters           |
| `vitest.json`                    | Machine-readable Vitest results                                 |
| `coverage/lcov.info`             | LCOV line coverage                                              |
| `coverage/coverage-summary.json` | JSON coverage summary used by the report script                 |
| `playwright-junit.xml`           | JUnit XML from `npm run test:e2e` (desktop and mobile projects) |

The Vitest suite covers backend RBAC and loan lifecycle rules, signed HTTP
verification and replay protection, reminder idempotency, HMAC primitives,
validation, workflow graph integrity, and representative view components.
Playwright covers the public browser flows on desktop and mobile; authenticated screenshots are captured separately by `scripts/capture-screenshots.mjs`.

Run the full local gate with:

```bash
npm run test:all
```

`test:all` runs typecheck, lint, workflow validation, Vitest, report generation,
and Playwright. It does not push or deploy anything.
